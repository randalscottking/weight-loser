# Quickstart Guide: Weight Loss Tracker

## Overview
This guide explains how to quickly get started with the weight loss tracker application.

## Installation
1. Clone the repository
2. Install dependencies with `pip install -r requirements.txt`
3. Initialize the database

## Getting Started
1. Start the application with `python -m weight_tracker.app`
2. Open your browser to `http://localhost:8000`
3. Register a new account or login

## Basic Usage
- Add weight entries through the web interface
- Set weight loss goals
- View progress through charts and statistics
